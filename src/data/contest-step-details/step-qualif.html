How to participate

Both schools and contestants participating from home can take part in these rounds. You may attempt one or several of them. Registration instructions will be published later — make sure you subscribe to our mailing list to be informed when it opens.

Task type

Very basic programming tasks, each covering one of the announced topics. You help a robot complete a task in a graphical environment: run the program step by step, watch the robot progress, and retry as many times as you like within the contest time. Supported environments include Blockly (similar to Scratch) and Python.

Topics

These rounds cover the basics of programming: sequences of instructions, basic loops (for), conditions (if/else), loops with conditions (while), variables, functions without parameters, advanced operators and conditions, functions with parameters, and lists.

Practical organization

Three independent online windows (typically December, January, and February). Each round lasts about 40 minutes and can be taken from school or home at any moment during the month. The exam takes place online: you need a computer with a web browser and a basic Internet connection. Help from AI or from another person is not allowed.

Qualify for the next rounds

Each age group gets the same tasks, but a different minimum set of topics to solve in order to qualify. These objectives will be announced in advance. Reaching them in any of the rounds is enough to qualify for the next stage.

How to prepare

Try last year’s tasks on concours.be-oi.be, in the “s'entraîner” section (tasks available in English). The last two tasks are typical of what you may encounter. More training tasks will be provided later.
