How to join

The challenge will be open during a full week at the end of November for educators so that they can run the contest with their students. After that week, the challenge will be open for a few days to anyone participating from home. More details will follow — make sure you subscribe to our mailing list to be informed when it opens.

Task type

Only logic puzzles involving computational thinking. No actual programming — neither block-based programming nor a code editor.

How to train

Try last year’s tasks on concours.be-oi.be, in the “s'entraîner” section (tasks available in English). The first five tasks are typical of what you may encounter. We will try to provide more training tasks later.

Practical organization

About 45 minutes, around the end of November. The exam takes place online: you need a computer with a web browser and a basic Internet connection. Supervised at school or under the rules announced for home participation that year. More details will follow.

Qualify for the next rounds

This stage is optional fun only. Results do not count toward qualification for later stages of beOI.
